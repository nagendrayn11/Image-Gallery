# 🖼️ Responsive Image Gallery

## 📌 About the Project

The Responsive Image Gallery is a modern and interactive web application developed using **HTML, CSS, and JavaScript**. It displays a collection of beautiful photographs in an attractive grid layout with smooth hover effects, animations, and an interactive lightbox for viewing images in full size.

The gallery is designed to work smoothly across desktops, tablets, and mobile devices. This project was developed as part of the **CodeAlpha Frontend Development Internship** to gain practical experience in frontend web development.

## ✨ Features

- 🖼️ Responsive image grid layout.
- 🔍 Full-size image preview using a lightbox.
- ⬅️➡️ Previous and next image navigation.
- 🎨 Attractive design with colors and gradient effects.
- 🏷️ Category-based image filtering.
- ✨ Smooth hover effects and transitions.
- 📱 Mobile-friendly and responsive interface.
- ⌨️ Keyboard navigation using arrow keys and Escape.
- ⚡ Lazy loading for improved image loading performance.

## 🛠️ Technologies Used

- **HTML5** – Structures the gallery and image cards.
- **CSS3** – Provides styling, grid layout, animations, and responsive design.
- **JavaScript** – Handles image filtering, lightbox functionality, and navigation.

## 🚀 How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three files are in the same folder.
4. Open `index.html` in your browser or use the Live Server extension.
5. Click any image to view it in full size.
6. Use the category buttons to filter images and the navigation arrows to browse.

**Note:** An internet connection is required to load the online images and Google Fonts used in the project.
